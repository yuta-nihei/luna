# UI.md

# Luna UI Design Guidelines

## 目的

LunaのUIは機能を見せるためではなく、開発者の思考を邪魔しないために存在する。

UIは目立たず、必要な時だけ現れること。

---

# デザイン原則

## Calm Interface

常に落ち着いた印象を保つ。

避けるもの

* 派手なアニメーション
* 強いコントラスト
* 不要な装飾
* 情報過多

---

## Content First

UIよりコードを優先する。

ユーザーが最も長く見るのはコードである。

画面内で最も目立つ要素はコードでなければならない。

---

## Keyboard First

すべての主要機能はキーボード操作可能にする。

マウスは補助操作とする。

---

## Minimal but Powerful

機能は豊富でも見た目はシンプルに保つ。

初見で理解できることを重視する。

# UI成功指標

ユーザーが初めて起動した時に

「何をすればよいか分かる」

こと。

そして1週間後には

「UIを意識しなくなる」

こと。

それがLunaの理想である。
